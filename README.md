## About PartnershipCoin

PartnershipCoin (PARC) is a BEP-20 token on BNB Smart Chain focused on building a simple Web3 ecosystem through the PARC Wallet app. The app is available on Google Play and supports wallet connection, QR Code payments, PARC transfers, transaction history and BNB Smart Chain interaction.

## Add PARC to MetaMask

The website button detects MetaMask before importing PARC. On desktop, it prefers the MetaMask provider through EIP-6963 discovery and avoids Brave Wallet when multiple wallet providers are injected.

The button requests BNB Smart Chain, then imports PARC with the official token logo:

```text
https://renrrs1-lab.github.io/PartnershipCoin/parc-logo-32.svg
```

On mobile, open the website inside the MetaMask Mobile browser and tap the button again.
